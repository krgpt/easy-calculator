아래 번호 항목을 클릭하면 각 기능의 사용 목적과 구체적인 텍스트 변환 사례를 확인하실 수 있습니다.

PDF 파일이나 논문, 인터넷 뉴스 기사 등을 복사해서 메모장에 붙여넣으면 문장 중간중간에 원치 않는 줄바꿈이 들어가 문단이 엉망이 되는 경우가 흔합니다. 이 버튼은 문장의 연결을 자연스럽게 공백 하나로 이어줍니다.

[입력 예시]

인공지능 기술이 급격히 발전함에 따라
많은 기업들이 업무 자동화를
도입하고 있습니다.

↓ [줄바꿈 ➔ 공백 변환] 클릭 시 ↓
[변환 결과]

인공지능 기술이 급격히 발전함에 따라 많은 기업들이 업무 자동화를 도입하고 있습니다.

수백 줄의 잡다한 로그 데이터나 문의글 본문 속에서 이메일 주소, 연락처, 웹 사이트 링크만 쏙쏙 골라내고 싶을 때 사용합니다. 정규표현식 패턴을 이용해 해당 형태의 텍스트만 모아서 정렬해 줍니다.

[입력 예시]

홍길동 (hong@example.com / 010-1234-5678)
문의 사항은 support@kylab.com 으로 주거나 02-999-8888로 연락바람.

↓ [이메일 주소만 추출] 클릭 시 ↓
[변환 결과]

hong@example.com
support@kylab.com

API 개발 중 한 줄로 복잡하게 꼬여있는 JSON 문자열을 들여쓰기가 들어간 예쁜 형태로 정렬(Beautify)하거나, 반대로 전송 용량을 줄이기 위해 공백을 모두 없애 한 줄로 압축(Minify)할 때 사용합니다.

[입력 예시]

{"name":"홍길동","age":30,"roles":["admin","user"]}

↓ [JSON 정렬 (Beautify)] 클릭 시 ↓
[변환 결과] 
{
  "name": "홍길동",
  "age": 30,
  "roles": [
    "admin",
    "user"
  ]
}

[입력 예시]

apple
banana

cherry
