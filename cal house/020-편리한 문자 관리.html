PDF나 뉴스 기사에서 텍스트를 복사할 때 문장 중간중간 엉뚱하게 들어간 줄바꿈을 공백 1칸으로 부드럽게 이어줍니다.

인공지능 기술이 급격히 발전함에 따라

인공지능 기술이 급격히 발전함에 따라 많은 기업들이 업무 자동화를 도입하고 있습니다.

수백 줄의 문의글이나 데이터 속에서 이메일 주소, 전화번호, 웹 URL 링크만 쏙쏙 골라 모아줍니다.

[입력 예시] 
홍길동 (hong@example.com / 010-1234-5678)
문의 사항은 support@kylab.com 으로 연락바람.
↓ [이메일 주소만 추출] 클릭 시 ↓
[변환 결과] 
hong@example.com
support@kylab.com

한 줄로 꼬인 JSON 문자열을 들여쓰기가 포함된 구조로 펼치거나(Beautify), 용량 축소를 위해 한 줄로 압축(Minify)합니다.

[입력 예시] 
{"name":"홍길동","age":30,"roles":["admin","user"]}
↓ [JSON 정렬 (Beautify)] 클릭 시 ↓
[변환 결과] 
{
  "name": "홍길동",
  "age": 30,
  "roles": [
    "admin",
    "user"
  ]
}

영문 텍스트 전체를 대/소문자로 바꾼 뒤, 여러 소스에서 수집된 중복 텍스트 줄을 하나만 남기고 완전히 정리합니다.

[입력 예시]

banana

엑셀 표에서 복사한 탭(Tab) 구분 데이터나 CSV 파일의 데이터를 프로그래밍에 바로 쓰는 JSON 배열 구조로 바꿔줍니다.

[입력 예시] 
이름	나이	부서
홍길동	30	개발팀
이순신	40	기획팀
↓ [CSV / Tab ➔ JSON 변환] 클릭 시 ↓
[변환 결과] 
[
  {
    "이름": "홍길동",
    "나이": "30",
    "부서": "개발팀"
  },
  {
    "이름": "이순신",
    "나이": "40",
    "부서": "기획팀"
  }
]

서버로 유출되지 않는 브라우저 내장 암호화 API로 Base64 변환, 무결성 검증용 SHA-256 해시를 뽑고 보안 패스워드를 발급합니다.

[입력 예시] 
MyPassword123!
↓ [SHA-256 보안 해시 생성] 클릭 시 ↓
[변환 결과] 
7760ae7f805a5df03f739678170c0c6628b0fae3b4f9a0dcf85b2e3e50bf7bc0

단어 표기 방식을 개발 규칙에 맞춰 카멜 케이스(myVariableName)나 스네이크 케이스(my_variable_name)로 상호 변환합니다.

[입력 예시] 
user profile image URL
↓ [스네이크 케이스 (snake_case)] 클릭 시 ↓
[변환 결과] 
user_profile_image_url
